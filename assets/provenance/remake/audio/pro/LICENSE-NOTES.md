Only 60 selected recordings were acquired (353,756,324 bytes), not complete
archives. The runtime source ledger contains 56 recordings (including existing
CC0 sources). The gem pass adds three recordings and the hand transformation pass
adds six; see ../GEM-AUDIO.md and ../HAND-UPGRADES.md.
Large recordings were selectively
extracted as 30-second PCM excerpts using HTTP byte ranges, without downloading
the whole recording. selected-sources.json records those exact ranges and the
hash of the local excerpt. A hash for an excerpt is not a hash of the full
original recording. Prior cancellation of multi-gigabyte bulk downloads remains
respected; no bundle/torrent was restarted.

The source files and their sidecars are excluded from Git by .gitignore. Edited
runtime files are included only as components of this finished game. The preview
is synchronized game footage; no individual studio-sound listening/download
catalog is distributed.
