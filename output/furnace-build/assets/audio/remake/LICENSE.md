The weapon, monster, impact, movement, interface and atmospheric sounds are
project edits of the credited studio recordings, preserving detailed attacks and
textures at 48 kHz. There are no arcade bleep or synthesized oscillator layers.
Music/ambience uses project compositions of studio stereo drones and swells.
Sources, source hashes, selected excerpts, recorded licenses, and per-cue recipes
are documented in assets/provenance/remake/audio/ in the project. Original studio
recordings are private working material and are excluded from the public source
asset archive. Runtime file hashes and exact per-file licenses: manifest.json.

The 24 enemy chatter/idle loops use **CC0 1.0** recordings from the following
creators. These chatter loops are project edits, distinct from the Sonniss bank.

- LucasDuff — insectoid monster clicking (performed voice/foley): https://freesound.org/people/LucasDuff/sounds/467700/

- PJ_Bear — monster_idle: https://freesound.org/people/PJ_Bear/sounds/707685/
- Joseph SARDIN / BigSoundBank — Chattering teeth #1, #2 and Tongue clicks:
  https://bigsoundbank.com/claquements-de-dents-s0789.html
  https://bigsoundbank.com/claquements-de-dents-2-s2190.html
  https://bigsoundbank.com/claquements-de-langue-s1038.html

Freesound acquisitions are the publisher's high-quality MP3 previews, decoded
for editing; BigSoundBank acquisitions are original WAVs. Output is 48 kHz mono
PCM; this does not imply the compressed sources gained fidelity. Edits include
performance selection, speed/pitch changes, filtering, subtle mouth/bone layers,
parallel saturation, loop fades and level calibration. No Devil Daggers recordings
are included in this chatter bank. Source URLs, hashes, cuts and licenses are
recorded in the project's provenance directory.
