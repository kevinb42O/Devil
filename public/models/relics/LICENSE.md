The GLB contains the original downloaded geometry, not an AI-generated asset.
The application adjusts scale, orientation, and materials at runtime.

The menu character uses the game's existing Quaternius Demon player model,
`/assets/models/crew-demon.glb`. Its provenance is recorded in
`assets/licenses/quaternius-demon.txt` in the project source.
The mist is a runtime volumetric shader, with no generated image assets.
